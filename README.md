# laravel-cars-parser

Базовый скрипт-концепт для парсинга данных корейского автопортала Encar. Проект написан в качестве демонстрации подхода к автоматизации сбора автомобильных данных и полностью изолирован в Docker.

## Технологический стек
* **Фреймворк:** Laravel 11 (PHP 8.2+)
* **База данных:** SQLite (работает «из коробки», не требует настройки сервера БД)
* **Окружение:** Docker + Docker Compose

## Архитектура и функционал (MVP-концепт)
* Парсер реализован в виде **Artisan-команды** `app:cars-parser`.
* Выполняется прямой запрос к API Encar с базовой подменой заголовков (User-Agent, Accept-Language) для обхода первичных фильтров.
* Результат парсинга первой страницы каталога форматируется и сохраняется локально в файл `cars.json` в формате JSON с поддержкой Unicode.

## Локальный запуск через Docker

Для запуска необходим установленный Docker Desktop.

1. Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone https://github.com
   cd laravel-cars-parser
   ```

2. Запустите сборку и контейнеры одной командой:
   ```bash
   docker compose up -d --build
   ```

3. Запустите команду парсера внутри контейнера:
   ```bash
   docker compose exec app php artisan app:cars-parser
   ```

4. Проверка результата:
   После вывода сообщения `done!`, собранные данные можно посмотреть внутри проекта в файле: `storage/app/cars.json` (или `storage/app/private/cars.json`).

Для остановки окружения используйте:
```bash
docker compose down
```
